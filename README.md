# CareerForge AI

CareerForge AI is an AI-powered career preparation platform that helps students and professionals:

- Build ATS-friendly resumes
- Analyze resumes against job descriptions
- Generate AI-powered cover letters
- Identify skill gaps
- Track job applications

## Tech Stack

### Frontend
- React (Vite)

### Backend
- Node.js
- Express.js

### Database
- MongoDB Atlas
